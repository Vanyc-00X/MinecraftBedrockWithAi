Neiro AI Mobs — Instructions
Pack version: 0.5.0

New: Upon first entering a fresh map, a friendly village
and a monster city (houses, mobs, roles) are automatically created.

Installation
------------
BDS + Ollama + start-bridge.cmd + behavior_pack
world_behavior_packs.json version: [0, 5, 0]
Beta APIs / GameTest experiment required for the world.

Startup
-------
1) Ollama
2) start-bridge.cmd
3) bedrock_server.exe
4) Connect to IP:19132

Upon first entry, a chat message regarding the auto-generated villages will appear.
Friendly village: approx. +36, +28 from spawn; monster city: -42, +34.

Commands
--------
!neiro / !neiro status / !neiro quest
!neiro village good|evil — manually add a settlement
!talk ...
